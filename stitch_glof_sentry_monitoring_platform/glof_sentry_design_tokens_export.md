# GLOF Sentry Design System Tokens

## Core Identity
**Name:** GLOF Sentry
**Vision:** High-fidelity, defense-grade glacial lake outburst flood monitoring.
**Theme Mode:** Dark (High Contrast)
**Typography:** Inter (Sans-serif) / JetBrains Mono (Data/Telemetry)

## Color Palette
The system uses a mission-critical color language:
- **Surface:** `#0c141c` (Deep Navy)
- **Primary:** `#4c6ef5` (Strategic Blue)
- **Secondary/Action:** `#22b8cf` (Cyan Telemetry)
- **Critical (L4):** `#ff6b6b` (Breach Warning)
- **Warning (L3):** `#fcc419` (High Risk)
- **Advisory (L2):** `#51cf66` (Stable/Nominal)
- **Outline:** `#323a42` (Grid/Separation)

## Spacing & Layout
- **Container Padding:** `16px`
- **Gutter:** `12px`
- **Corner Radius:** `4px` (Rigid/Functional)
- **Grid:** 8px base unit

## Component Tokens
- **Top Bar:** Fixed, 64px height, `#0c141c` background.
- **Bottom Nav:** Fixed, 56px height, `#141c24` background.
- **Data Cards:** `#141c24` surface, `#323a42` border.
- **Status Badges:** Caps labels, 10px font size, semi-bold.

## Typography Scale
- **Headlines:** font-size: 24px, tracking: -0.02em
- **Sub-headers:** font-size: 14px, tracking: 0.05em, uppercase
- **Telemetry/Data:** font-family: 'JetBrains Mono', font-size: 13px
- **UI Labels:** font-size: 12px, font-weight: 500, uppercase
